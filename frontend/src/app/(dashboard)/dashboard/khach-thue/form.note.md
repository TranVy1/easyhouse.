- Route: `/dashboard/khach-thue`
- Frontend:
  - `frontend/src/app/(dashboard)/dashboard/khach-thue/page.tsx`
  - `frontend/src/app/(dashboard)/dashboard/khach-thue/table.tsx`

  - `POST /api/khach-thue`

  - `DELETE /api/khach-thue/{id}`
  - `POST /api/upload` for CCCD images
- Backend:
  - `KhachThueController`
  - `KhachThueService`
  - `KhachThueRequest`, `KhachThueResponse`

  - `khach_thue`
