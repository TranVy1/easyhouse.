# Phong form note

- Route: `/dashboard/phong`
- Frontend:
  - `frontend/src/app/(dashboard)/dashboard/phong/page.tsx`
  - `frontend/src/app/(dashboard)/dashboard/phong/table.tsx`
  - upload: `frontend/src/components/ui/phong-image-upload.tsx`
- Router links: sidebar -> `/dashboard/phong`.
- Form fields: `maPhong`, `toaNha`, `tang`, `dienTich`, `giaThue`, `tienCoc`, `moTa`, `anhPhong`, `tienNghi`, `soNguoiToiDa`, `trangThai`.
- API:
  - `GET /api/phong?toaNha={id}&trangThai={status}&limit=100`
  - `GET /api/toa-nha`
  - `POST /api/phong`
  - `PUT /api/phong/{id}`
  - `DELETE /api/phong/{id}`
  - `POST /api/upload` for images
- Backend:
  - `PhongController`
  - `PhongService`
  - `PhongRepository`
  - `NhaTroController` for dropdown
- DB:
  - `phong`
  - `nha_tro`
  - `hop_dong` for current tenant/contract display
- Query:
  - `toaNha` -> `nha_tro_id`.
  - `trangThai` -> `AVAILABLE`/`RENTED`/`MAINTENANCE`.
- Logic:
  - Create/update same form.
  - Amenities stored in `phong.tien_nghi` jsonb.
  - Room images stored in `phong.anh_phong` jsonb.
  - Status `daDat` exists in frontend but backend maps to `AVAILABLE`.

  - Upload needs Cloudinary config for real image URLs.
