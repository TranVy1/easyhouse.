# Ho so form note

- Route: `/dashboard/ho-so`
- Frontend: `frontend/src/app/(dashboard)/dashboard/ho-so/page.tsx`
- Router links: sidebar -> `/dashboard/ho-so`.
- Profile fields: `name`, `phone`, `address`, `avatar`.
- Password fields: `oldPassword`, `newPassword`, `confirmPassword`.
- API:
  - `GET /api/user/profile`
  - `PUT /api/user/profile`
  - `POST /api/user/change-password`
  - external address API: `https://provinces.open-api.vn/api/...`
- Backend:
  - `UserController`
  - `UserService`
  - `UserRequest`, `ChangePasswordRequest`, `UserResponse`
- DB:
  - `nguoi_dung`
- Query:
  - Bearer token from `session.accessToken` sent manually.
- Logic:
  - Loads profile when NextAuth session exists.
  - Address picker composes `detail, ward, district, province` into one string.
  - Password change checks confirm password client-side.
  - On profile save, calls NextAuth `update`.
