# Su co form note

- Route: `/dashboard/su-co`
- Frontend:
  - `frontend/src/app/(dashboard)/dashboard/su-co/page.tsx`
  - `frontend/src/app/(dashboard)/dashboard/su-co/table.tsx`
  - upload: `frontend/src/components/ui/su-co-image-upload.tsx`
- Router links: sidebar -> `/dashboard/su-co`.
- Form fields: `phongId`, `khachThueId`, `tieuDe`, `moTa`, `loaiSuCo`, `uuTien`, `trangThai`, `ghiChuChuNha`, `anhSuCo[]`.
- API:
  - `GET /api/su-co`
  - `GET /api/phong`
  - `GET /api/khach-thue`
  - `GET /api/hop-dong`
  - `POST /api/su-co`
  - `PUT /api/su-co/{id}`
  - `DELETE /api/su-co/{id}`
  - `POST /api/upload` for images
- Backend:
  - `SuCoController`
  - `SuCoService`
  - `SuCoRequest`, `SuCoResponse`
- DB:
  - `su_co`
  - `phong`
  - `khach_thue`
  - `hop_dong` for auto-select active tenant
- Query:
  - Full load then frontend filters by status/type/priority.
- Logic:
  - Selecting room finds active contract `hoatDong`, auto-fills representative tenant.
  - New incident omits `trangThai`, backend defaults `PENDING`.
  - Edit can update status and owner note.
  - Images stored in `su_co.anh_su_co` jsonb.
- Can luu y:
  - Frontend field `mucDoUuTien`; request field `uuTien`; response maps alias.
