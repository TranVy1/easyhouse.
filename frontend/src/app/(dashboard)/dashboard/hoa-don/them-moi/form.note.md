# Them moi hoa don form note

- Route: `/dashboard/hoa-don/them-moi`
- Frontend: `frontend/src/app/(dashboard)/dashboard/hoa-don/them-moi/page.tsx`
- Router links: cancel/success -> `/dashboard/hoa-don`.
- Form fields: `maHoaDon`, `hopDong`, `phong`, `khachThue`, `thang`, `nam`, `tienPhong`, `tienDien`, `soDien`, `chiSoDienBanDau`, `chiSoDienCuoiKy`, `tienNuoc`, `soNuoc`, `chiSoNuocBanDau`, `chiSoNuocCuoiKy`, `phiDichVu[]`, `tongTien`, `daThanhToan`, `conLai`, `trangThai`, `hanThanhToan`, `ghiChu`.
- API:
  - `GET /api/hoa-don/form-data`
  - `GET /api/hoa-don/latest-reading?hopDong={id}&thang={m}&nam={y}`
  - `POST /api/hoa-don`
- Backend:
  - `HoaDonController.create`
  - `HoaDonController.getFormData`
  - `HoaDonController.getLatestReading`
  - `HoaDonService`
- DB:
  - `hoa_don`
  - `chi_tiet_hoa_don`
  - `hop_dong`
  - `phong`
  - `khach_thue`
- Query:
  - Latest reading finds latest invoice by contract, then reads last electricity/water end index from line item `mo_ta`.
- Logic:
  - Auto-generates invoice code `HDyyyyMMddxxx` on page load.
  - Selecting contract auto-fills room, representative tenant, rent, service fees.
  - Electricity = `(chiSoDienCuoiKy - chiSoDienBanDau) * hopDong.giaDien`.
  - Water = `(chiSoNuocCuoiKy - chiSoNuocBanDau) * hopDong.giaNuoc`.
  - Total = rent + electricity + water + service fees.
  - Validates indices non-negative and ending >= starting.
- Can luu y:
  - Backend stores electricity/water as invoice detail rows, not in separate meter table.
