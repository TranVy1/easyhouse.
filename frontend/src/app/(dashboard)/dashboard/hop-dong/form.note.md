# Hop dong list/status note

- Route: `/dashboard/hop-dong`
- Frontend:
  - `frontend/src/app/(dashboard)/dashboard/hop-dong/page.tsx`
  - `frontend/src/app/(dashboard)/dashboard/hop-dong/table.tsx`
- Router links: create -> `/dashboard/hop-dong/them-moi`; edit/detail -> `/dashboard/hop-dong/{id}`.
- API:
  - `GET /api/hop-dong?limit=100`
  - `GET /api/phong?limit=100`
  - `GET /api/khach-thue?limit=100`
  - `GET /api/toa-nha?limit=100`
  - `PUT /api/hop-dong/{id}` for status update
  - `DELETE /api/hop-dong/{id}`
- Backend:
  - `HopDongController`
  - `HopDongService`
- DB:
  - `hop_dong`
  - `phong`
  - `khach_thue`
  - `nha_tro`
- Query:
  - List uses full load, then client filters by status and building.
- Logic:
  - Quick status actions set `hoatDong`, `hetHan`, `daHuy`.
  - View modal renders contract info and payment cycle.
  - sessionStorage key `hop-dong-data` used as cache.
- Can luu y:
  - Backend maps `hoatDong`/`hetHan`/`daHuy` to `ACTIVE`/`EXPIRED`/`TERMINATED`.
