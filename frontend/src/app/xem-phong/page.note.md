# Xem phong page note

- Route: `/xem-phong`
- Frontend: `frontend/src/app/xem-phong/page.tsx`
- Router links: room modal only; public route from `/`
- API:
  - `GET /api/phong?limit=100&toaNha={id}&trangThai={status}`
  - `GET /api/toa-nha`
- Backend:
  - `PhongController.getAllPhong`
  - `PhongService.getAllPhong`
  - `NhaTroController.getAll`
- DB:
  - `phong`
  - `nha_tro`
  - maybe `hop_dong` for `hopDongHienTai`
- Query:
  - `toaNha` query maps to backend `nha_tro_id`.
  - `trangThai` maps `trong`, `dangThue`, `baoTri`, `daDat`.
- Logic:
  - Public room list with building/status filters.
  - Shows amenities, price, images, status badge.
  - `daDat` is frontend-only-ish; backend maps it to `AVAILABLE`.
- Can luu y:
  - Query `limit=100` is sent, but backend controller may ignore pagination.
